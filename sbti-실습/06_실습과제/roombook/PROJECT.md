# roombook — 사내 회의실 예약 시스템 (연습용 가상 프로젝트)

실제 운영 시스템이 아니라 **교육 실습용으로 만든 가짜 코드베이스**입니다.

- 프론트: 순수 HTML/CSS/JS
- 백엔드: Node.js (Express 스타일)
- 배치: Python
- DB: PostgreSQL

## 실행 (실습에서는 실행하지 않습니다)

```
npm install
npm run dev
```

## 담당

| 영역 | 담당 |
|---|---|
| 화면 | 프론트 파트 |
| 서버·배치 | 백엔드 파트 |
| DB | 데이터 파트 |
