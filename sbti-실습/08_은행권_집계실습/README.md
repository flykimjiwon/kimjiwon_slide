# 시난은행 집계 실습 단말

**`은행권_집계실습.html` 더블클릭. 끝.** (설치·인터넷 불필요, USB에서 바로 동작)

> 전부 가상 데이터 — 실존 은행·상품·직원과 무관합니다.

## 흐름은 하나뿐

1. 문제 탭에서 **AI 요청문 복사 (F2)**
2. 사내 AI(택가이/Qwen)에 붙여넣어 **쿼리를 받는다**
3. 받은 쿼리를 붙여넣고 **실행＋채점 (F8)** → `[정상]` / `[주의]` / `[불일치]` 자동 판정

- 쿼리는 Oracle·MySQL 문법 그대로 붙여넣어도 됩니다 (NVL·TO_DATE·백틱·FETCH FIRST 등 자동 호환, ROWNUM만 안내)
- 문제 2는 상위 20개가 맞아도 숨은 검증(전체 988행·PV=0 376개)까지 자동 확인합니다
- `디자인시안_4종.html` 은 스킨 후보 비교용 기록입니다
