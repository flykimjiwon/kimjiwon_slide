문제 1 · 카드 추천실적 상위 10명 ★★★

2026 상반기 · 카드 상품 · ref_status='NORMAL' 만 실적 · 재직자만 · 상위 10명이되 10위 동점자 포함 · 출력 9개 컬럼

채점 기준 (5점)

#항목확인 방법
1동점 처리 — RANK() 사용 (LIMIT 10 아님)RANK 가 있는가, 정렬키에 사번 같은 고유값이 섞이면 동점이 사라진다
2COUNT(DISTINCT cust_no) 로 고객수 별도 계산건수와 고객수가 다른 값인가
3취소건수를 FILTER/CASE 로 같이 집계WHERE ref_status='NORMAL' 로 걸어버리지 않았는가
4재직자 필터가 집계 전순위에 구멍(1,2,4,5…)이 없는가
5취소율 0 나눗셈 방어NULLIF 또는 CASE 가 있는가

정답 쿼리 Claude

WITH card_ref AS (
    SELECT r.ref_emp_no, r.cust_no, r.ref_status
    FROM referral r
    JOIN product  p ON p.prod_cd = r.prod_cd
    JOIN employee e ON e.emp_no  = r.ref_emp_no
    WHERE p.prod_type = 'CARD'
      AND e.emp_status = '재직'              -- 순위 매기기 "전"에 제외
      AND r.apply_dt >= DATE '2026-01-01'
      AND r.apply_dt <  DATE '2026-07-01'    -- < 7월 1일
),
agg AS (
    SELECT ref_emp_no,
           COUNT(*) FILTER (WHERE ref_status = 'NORMAL')                AS 추천건수,
           COUNT(DISTINCT cust_no) FILTER (WHERE ref_status = 'NORMAL') AS 추천고객수,
           COUNT(*) FILTER (WHERE ref_status = 'CANCELLED')             AS 취소건수
    FROM card_ref GROUP BY ref_emp_no
),
ranked AS (
    SELECT a.*, RANK() OVER (ORDER BY a.추천건수 DESC, a.추천고객수 DESC, a.ref_emp_no) AS 순위
    FROM agg a WHERE a.추천건수 > 0
)
SELECT r.순위, r.ref_emp_no AS 사번, e.emp_nm AS 직원명, b.branch_nm AS 영업점명,
       e.position AS 직급, r.추천건수, r.추천고객수, r.취소건수,
       ROUND(r.취소건수 * 100.0 / NULLIF(r.추천건수 + r.취소건수, 0), 1) AS "취소율(%)"
FROM ranked r
JOIN employee e ON e.emp_no    = r.ref_emp_no
JOIN branch   b ON b.branch_cd = e.branch_cd
WHERE r.순위 <= 10
ORDER BY r.순위;

문제 2 · 앱 페이지뷰 집계 ★★★

2026년 7월 · 폐쇄 페이지 제외 · PV / UV(비로그인 제외) / 세션수 / 평균체류초 · 조회 0건 페이지도 0으로 표시 · PV 내림차순 상위 20

채점 기준 (5점)

#항목확인 방법
1LEFT JOIN 사용INNER 가 아닌가
2기간 조건이 ON 절에WHERE 에 있으면 0건 페이지가 사라진다
3COUNT(l.log_id) (COUNT(*) 아님)0건 페이지의 PV 가 0 인가 1 인가
4UV = COUNT(DISTINCT cust_no)비로그인이 빠졌는가
5평균체류 COALESCE0건 페이지가 NULL 인가 0 인가

정답 쿼리 Claude

SELECT p.page_cd AS 페이지코드, p.page_nm AS 페이지명, p.category AS 카테고리,
       COUNT(l.log_id)              AS "PV"      -- COUNT(*) 아님
       , COUNT(DISTINCT l.cust_no)    AS "UV"
       , COUNT(DISTINCT l.session_id) AS 세션수
       , COALESCE(ROUND(AVG(l.stay_sec)::numeric, 1), 0) AS 평균체류초
FROM app_page p
LEFT JOIN page_view_log l
       ON l.page_id  = p.page_id
      AND l.view_at >= TIMESTAMP '2026-07-01 00:00:00'
      AND l.view_at <  TIMESTAMP '2026-08-01 00:00:00'   -- ★ 기간 조건은 ON 절에
WHERE p.close_dt IS NULL OR p.close_dt >= DATE '2026-07-01'
GROUP BY p.page_cd, p.page_nm, p.category, p.page_id
ORDER BY "PV" DESC, p.page_id
LIMIT 20;
이 문제의 핵심은 ② 입니다. 기간 조건을 WHERE 에 두면 로그가 없는 페이지는 view_at 이 NULL 이라 조건에서 탈락합니다. LEFT JOIN 이 사실상 INNER JOIN 이 되어 조회 0건 페이지가 통째로 사라집니다. 쿼리는 에러 없이 돌고 결과도 그럴듯해서 눈으로는 못 잡습니다.
