# SBTI 강사 가이드 사이트

두 번의 독립 조사와 다섯 종의 운영 문서를 하나로 묶은 **강사 전용 레퍼런스**.
자체 완결 HTML 한 개 — 폐쇄망 노트북에서 파일을 더블클릭하면 그대로 열린다.

```
open guide/index.html
```

## 쓰는 법

| 하고 싶은 것 | 하면 되는 것 |
|---|---|
| 그냥 읽기 | `index.html` 열기 |
| 강의 중 답 찾기 | `/` 누르고 키워드 입력, `Esc`로 해제 |
| 인쇄 | 사이드바 `PRINT` 또는 `⌘P` |
| 내용 수정 | `_source/data/*.md` 고치고 `python3 build.py` |
| **디자인 다시 하기** | **`_source/PROMPT.md` A절을 Claude에 붙이고 `_source/data/` 첨부** |
| 부분만 수정 | `_source/PROMPT.md` B-1 |
| 인쇄 핸드아웃 | `_source/PROMPT.md` B-2 |
| 슬라이드 보강 장표 | `_source/PROMPT.md` B-3 |

## 먼저 알아야 할 것

1. **두 조사가 6곳에서 갈렸다.** 권 I 2장에 전문이 있다. 그중 **AI 기본법 시행일(2026-01-22 vs 2026-07-21)은 미해결**이며 법무 확인이 필요하다. 확정 전에는 강의에서 단정하지 않는다.
2. **P0 차단항목 15개**가 권 I 3장에 있다. 도구 개수(13/14/37/50+ 충돌), 버전 불일치, 404 링크, 87.5% 근거, "문서 즉시 학습" 표현 등.
3. **근거 등급 A~E**로 모든 사실을 표기했다. 강의에서는 **A·B만 단정형**으로 말한다.
4. 🔴 **사내 교육용.** 실명 후기·부서별 사용량·내부 시스템명·경로가 들어 있다. 외부 배포 전 마스킹과 승인이 필요하다 (`_source/MANIFEST.md` §5).
