당신은 시니어 프로덕트 디자이너 겸 프론트엔드 엔지니어입니다.
첨부한 마크다운 문서들을 **하나의 자체 완결 HTML 레퍼런스 사이트**로 만들어 주세요.

### 무엇인가

신한은행 사내 강의 **SBTI 1·2·3** (AI 코딩 트렌드 / 사내 AI 코딩 에이전트 소개 / 활용 사례)의
**강사 전용 가이드**입니다. 강사 1명이 3일 동안 총 120명 앞에 섭니다.

이 사이트는 마케팅 페이지가 아닙니다. **혼자 쓰는 작업 도구**입니다.
쓰이는 순간은 정확히 두 번뿐입니다.

1. **강의 전날 밤** — 책상에서 처음부터 끝까지 정독하며 무엇을 말하고 무엇을 말하지 않을지 정한다.
2. **강의 중 Q&A** — 질문이 들어온 30초 안에 키워드로 검색해서 답을 찾는다.

그래서 **읽기 속도**와 **찾기 속도**가 심미성보다 우선입니다. 다만 촌스러우면 안 됩니다.

### 누가 읽는가

- 한국어 원어민, 15년차 개발자, AI 코딩 도구를 직접 만든 사람
- 화면 앞에서 장시간 정독한다 → 긴 호흡의 본문 가독성이 핵심
- 표와 체크리스트를 많이 본다 → 표 디자인이 이 사이트의 승부처
- 인쇄해서 들고 들어갈 수도 있다 → print 스타일시트 필수

### 반드시 지킬 기술 제약

1. **단일 HTML 파일. 외부 요청 0건.** 폐쇄망 사내 노트북에서 파일을 더블클릭해도 그대로 열려야 합니다. 웹폰트 CDN, 외부 스크립트, 외부 이미지, fetch 전부 금지. CSS·JS 인라인, 이미지는 인라인 SVG나 data URI.
2. **한글 폰트는 시스템 스택.** 다운로드 폰트를 쓸 수 없으므로 `"Pretendard Variable", Pretendard, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR"` 순으로 폴백합니다. 차별화는 폰트 파일이 아니라 **타이포그래피 시스템**(스케일·자간·굵기 대비·괘선·번호 체계)에서 만들어 주세요.
3. **전체 검색.** `/` 키로 포커스, 입력하면 일치하지 않는 블록을 숨기고 일치 부분을 하이라이트, `Esc`로 해제, 일치 개수 표시. 이 사이트에서 가장 자주 쓰는 기능입니다.
4. **사이드바 내비게이션.** 권 단위 아코디언 + h2/h3 앵커. 스크롤에 따라 현재 위치를 표시(IntersectionObserver).
5. **다크 기본 + 라이트 토글**, `localStorage` 유지.
6. **print CSS.** 사이드바·버튼 숨김, 표와 섹션 페이지 분할 방지, 링크 색 제거.
7. 반응형. 1180px 이하에서는 사이드바를 드로어로.
8. 접근성: 시맨틱 heading 위계, 대비 4.5:1 이상, 키보드 이동 가능, `prefers-reduced-motion` 존중.

### 콘텐츠 렌더링 규칙 (중요)

- 원문에 나오는 **🟢 / 🟡 / 🔴** 는 **근거 등급 A / B / E** 를 뜻합니다. 이모지를 그대로 두지 말고 **타이포그래픽 배지**로 바꿔 주세요.
  - 단, **h1·h2 제목에서는** 같은 이모지가 등급이 아니라 **경보 표시**입니다 (예: `## 🔴 두 조사가 충돌한 지점`). 제목에서는 작은 상태 점으로 처리하세요.
- **⚠️ 🚨** 도 이모지 대신 시각 마커로.
- 표가 47개 이상 나옵니다. **표가 이 사이트의 주인공입니다.** 헤더 고정 톤, 행 hover, 우측정렬 숫자 열에는 tabular-nums, 가로 스크롤은 표 안에서만.
- 코드 블록에는 언어 라벨. 자동 하이라이팅은 하지 마세요(외부 라이브러리 금지, 그리고 대부분 코드가 아니라 다이어그램·의사코드입니다).
- 체크박스 `- [ ]` 는 실제로 보이는 체크박스 모양으로.

### 디자인 방향

**당신이 정하세요.** 다만 아래는 피해 주세요.

- 보라색 그라디언트 + 흰 배경
- Inter / Roboto / 시스템 기본값에 기대는 무개성 타이포
- SaaS 랜딩페이지 문법 (히어로 + 3열 카드 + CTA)
- 과한 모션. 이 문서는 스크롤하며 읽는 물건입니다

기존 구현은 **"브리핑 도크"** — 잉크블랙 + 시그널 앰버 단색 강조, 헤어라인 괘선, 여백에 권 표시 레일, 메타데이터 전부 모노스페이스 방향으로 만들었습니다.
**같은 방향으로 갈 필요 없습니다.** 더 나은 안이 있으면 다른 방향으로 가되, 하나의 관점을 끝까지 밀어붙여 주세요. 문서가 길기 때문에 **일관성이 곧 품질**입니다.

기억에 남을 요소 하나만 확실히 만들어 주세요. 그게 등급 배지 체계든, 여백의 방향 표시든, 표 조판이든 상관없습니다.

## C. 이 프롬프트를 쓸 때 자주 놓치는 것

- **"요약하지 말 것"을 명시하지 않으면 Claude는 반드시 요약합니다.** 문서가 3,900줄이 넘어서 그렇습니다. A절 마지막 문단을 지우지 마세요.
- 검색 기능은 명시하지 않으면 안 만들어 줍니다. 이 사이트에서 제일 중요한 기능인데도 그렇습니다.
- 폐쇄망 제약(외부 요청 0건)을 안 쓰면 십중팔구 Google Fonts를 붙입니다. 사내 노트북에서는 폰트가 안 뜨고 렌더링이 무너집니다.
- 이모지 → 배지 변환 규칙을 안 쓰면 🟢🟡🔴이 그대로 남습니다. 사내 문서로는 가벼워 보입니다.
- 분량이 크므로 한 번에 완성되지 않을 수 있습니다. **"권 I부터 순서대로, 권마다 나눠서"** 로 요청하면 안정적입니다.
