Terminal과 VS Code Extension, 두 제품 모두 같은 엔진을 씁니다.

Terminal Agent

프로젝트 루트에서 바로 실행. 파일·셸·git 작업과 자연스럽게 연결됩니다.

VS Code Extension

에디터 안에서 같은 엔진과 같은 도구 실행 루프를 사용합니다.

Same Engine

터미널/VS Code UI만 다르고 모델 권한, 로그, API Key 관리 체계는 동일합니다.
