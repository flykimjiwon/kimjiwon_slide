# SBTI 실습 참가자 사전안내

대상: SBTI 1·2·3 참가자
수업시간: 120분
준비 완료 권장 시점: 수업 3일 전

## 수업에서 할 일

이번 수업은 AI 도구를 구경하는 데서 끝나지 않습니다.

- 코드 저장소를 먼저 이해하기
- AI에게 작은 작업을 맡기기
- 변경된 diff를 직접 확인하기
- 테스트·빌드·실행으로 결과 검증하기
- 잘못되거나 위험한 제안을 거절하기
- 문서 지식과 MCP의 사용 범위 이해하기

## 개인 준비물

- [ ] 사내망 접속 가능한 노트북
- [ ] 전원 어댑터
- [ ] 마우스 또는 익숙한 입력장치
- [ ] VS Code 실행 확인
- [ ] Terminal/명령 프롬프트 실행 확인
- [ ] Git 기본 명령 사용 가능
- [ ] 택가이Web SSO 로그인 성공
- [ ] 택가이코드 개인 API Key 발급·등록
- [ ] 택가이코드 Terminal 또는 VS Code Extension 실행 성공
- [ ] 교육용 저장소 다운로드 또는 제공 경로 접근 성공

## 3분 사전 확인

다음 네 가지가 되면 준비 완료입니다.

1. 택가이Web에 로그인할 수 있다.
2. 택가이코드에서 새 대화를 시작할 수 있다.
3. 교육용 저장소를 VS Code로 열 수 있다.
4. 안내된 테스트 또는 실행 명령을 한 번 실행할 수 있다.

하나라도 안 되면 수업 당일보다 사전에 운영 담당자에게 알려주세요.

## 안전수칙

수업에서는 제공된 샘플 코드와 문서만 사용합니다.

입력하지 않는 것:

- 실제 고객정보와 개인정보
- 운영계 데이터
- 비밀번호, API Key, token, 인증서, 비밀키
- 승인되지 않은 운영 코드와 내부 문서
- 외부로 공유하면 안 되는 URL·화면·로그

실행 전 확인:

- 명령이 어느 폴더와 파일을 대상으로 하는가?
- 읽기인가, 수정인가, 삭제인가, 외부 전송인가?
- 새 dependency를 설치하는가?
- 예상하지 못한 권한을 요구하는가?

실행 후 확인:

- 어떤 파일이 바뀌었는가?
- diff가 요구사항에 맞는가?
- 테스트·빌드·실행 결과는?
- 불필요한 파일·dependency·로그가 생겼는가?
- 변경 내용을 AI 없이 설명할 수 있는가?

## 실습 방식

- 4명씩 한 조로 진행합니다.
- 직접 타이핑하는 사람을 교대합니다.
- 파란색 표시는 완료, 노란색 표시는 도움이 필요하다는 뜻입니다.
- helper는 정답을 대신 입력하지 않고, 참가자가 직접 문제를 해결하도록 돕습니다.
- 네트워크나 계정 장애가 발생하면 캡처된 AI 대화와 diff를 이용한 대체 실습으로 전환합니다.

운영 담당자가 아래 항목을 수집하면 조 편성과 지원 준비에 사용합니다.

5. Java·ProFrame·WebSquare 경험

7. 택가이Web 로그인 여부

9. VS Code Extension 실행 여부
10. API Key와 모델 접근 여부
