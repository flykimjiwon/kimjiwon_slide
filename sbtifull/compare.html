원본 ↔ 공개본 대조

S.B.T.I 강의 3부작의 원본과 외부 공개용 모자이크본을 나란히 확인하는 페이지입니다. 원본 파일(sbti1/ sbti2/ sbti3/)은 수정하지 않았고, 공개본(sbtifull/)은 원본을 읽어 새로 생성한 사본입니다.

이 페이지는 내부 검수용입니다. 왼쪽 원본 패널에는 실명·부서명·회사 식별자가 그대로 들어 있습니다. 외부에 공유할 링크는 /sbtifull 하나뿐입니다. 이 대조 페이지 주소는 공유하지 마세요.

! 별첨 원본 경로는 열려 있음

/sbti3/assets/attachments/ 의 2025 테크 타운홀·부서장회의 자료와 시연영상 5종은 원본 경로에서 그대로 받아집니다. 강의 슬라이드가 아니라 경영 회의 자료라 별도 판단이 필요합니다.

! 제품 UI 스크린샷 잔여

터미널·VS Code 캡처 약 25장에 제품 워드마크나 .tgc 경로가 남아 있을 수 있습니다. 회사 식별자는 아니지만 익명화 방침과는 어긋납니다. 넘겨보며 확인하세요.

! 집계 수치 유지

사용자 2,018명 · 주간 34.9억 토큰 · API Key 465건 등 총계는 그대로 뒀습니다. 부서명을 익명화해 특정은 어렵지만, 공개 여부는 판단이 필요합니다.

! 원본 URL 접근

/sbti1 /sbti2 /sbti3 는 지금도 공개 접근됩니다. 비밀번호를 걸기 전까지는 원본 실명이 소스에 노출된 상태입니다.

6. 재생성 방법

  • python3 scripts/build_sbtifull.py — 원본을 읽어 sbtifull/ 를 통째로 다시 만듭니다 (기존 폴더 삭제 후 생성).
  • python3 scripts/redact_sbtifull_assets.py — 이미지 마스킹·제외를 적용합니다. 반드시 위 스크립트 다음에 실행합니다.
  • 치환 규칙을 고치려면 build_sbtifull.py 상단의 NAME_MAP / DEPT_MAP / ORG_MAP / PRODUCT_MAP 을 수정합니다.
  • 원본 sbti1~3/ 는 두 스크립트 모두 읽기만 합니다.
