MAS · MULTI-AGENT SYSTEM

싱글은 빠르게, MAS는 AI 팀으로

MAS(Multi-Agent System)는 한 세션 안에서 여러 에이전트가 역할을 나눠 일하는 구조다.
멀티를 켜면 하네스가 요청을 읽고 리뷰·비교·찾기 전략을 고른 뒤, 오케스트레이터가 에이전트들을 실행·관리한다.

SINGLE · 간단한 일
  • 에이전트 1개가 같은 툴 루프를 수행
  • 질문·단일 파일은 혼자 빠르게 처리
  • 도구 결과를 자기 히스토리에 넣고 반복
