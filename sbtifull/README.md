# sbtifull — S.B.T.I 강의 3부작 공개본 (모자이크)

외부(링크드인 등) 공유용 **78장 연속 덱**이다(2026-08-26 증분 재빌드). 1부 23장 + 2부 42장 + 3부 13장이
하나의 흐름으로 이어지고, ← → 가 부 경계를 그대로 통과한다. 뷰어는 부별 장수를 동적으로 세므로
재빌드로 장수가 바뀌어도 뷰어 코드는 손댈 필요 없다.
`sbti1/` `sbti2/` `sbti3/` 원본에서 **생성된 사본**이며, 원본은 이 폴더의 어떤 스크립트도 수정하지 않는다.

| | 주소 |
|---|---|
| 공개본 통합 뷰어 | `/sbtifull` |
| 원본 ↔ 공개본 대조 (내부 검수용) | `/sbtifull/compare` |
| EASY AI 용어사전 (원본 그대로 사용) | `/easyai` |

## ⚠️ `<base href="/sbtifull/">` 를 지우지 말 것

배포가 `cleanUrls: true` · `trailingSlash: false` 라서 주소가 `/sbtifull`(뒤 슬래시 없음)에 머문다.
`<base>` 가 없으면 상대경로 `sbti1/index.html` 이 `/sbtifull/` 이 아니라 `/` 기준으로 풀려
**`/sbti1` — 마스킹 안 된 원본**이 iframe에 실린다. 실제로 그렇게 배포된 적이 있다(2a2df49에서 수정).

이중 안전장치로 공개본 `<head>` 에 `<meta name="x-sbti-build" content="mosaic">` 표식을 박아 두고,
뷰어가 iframe마다 확인한다. 표식이 없으면 화면을 지우고 경고를 띄운 뒤 멈춘다 — 원본이 조용히
노출되는 대신 눈에 보이게 실패한다.

## 왜 새로 만들었나

원본 `sbti2`는 실명·부서명을 CSS `filter:blur(4px)` 45곳으로 가리고 있었다.
**blur는 화면에서만 흐릴 뿐 HTML 소스에는 원문이 그대로 남는다.** 소스 보기나 개발자도구로 바로 읽힌다.
공개본은 문자열 자체를 치환하고 blur 필터를 걷어냈다.

## 재생성

```bash
cd my-projects/kimjiwon_slide
python3 scripts/build_sbtifull.py          # 문자열 치환 + 덱 폴더 재생성
python3 scripts/redact_sbtifull_assets.py  # 이미지 마스킹·제외 (반드시 위 스크립트 다음)
```

`build_sbtifull.py` 는 덱 폴더(`sbti1~3/`)만 갈아엎고 `index.html` · `compare.html` · 이 README는 건드리지 않는다.
치환 규칙은 스크립트 상단의 `NAME_MAP` / `DEPT_MAP` / `ORG_MAP` / `PRODUCT_MAP` 에 있다.

검증은 빌드가 자동으로 돈다. **판정이 "통과"가 아니면 배포하지 않는다.** 검사 항목:

| 항목 | 통과 조건 |
|---|---|
| 금칙어 잔존 | 실명 20 · 부서 22 · 회사/시스템 13 · 제품 약칭 6 = 61종이 0건 |
| 원본 역링크 잔존 | `vercel.app/sbti{1,2,3}` · `assets/sbti{N}.pdf` · `attachments/` 가 0건 |
| 깨진 참조 | 참조하는데 파일이 없는 asset이 0건 |

결과는 `_build_report.json` 에 남는다.

배포 뒤에는 **반드시 브라우저로 iframe 실제 URL을 확인한다.** curl 로 HTML만 받아보면
상대경로가 어떻게 풀리는지 알 수 없어 위의 `<base>` 사고를 놓친다.
