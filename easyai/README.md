# EASY AI — AI 코딩 용어사전 복원·운영 안내

이 폴더가 「AI 코딩 용어사전」(EASY AI)의 전체 정본입니다. 이후 세션에서 "이지에이아이 풀받아", "용어사전 전부 복원해", "발표자료 싹 다 받아"라고 하면 `origin/main`의 `easyai/` 전체를 기준으로 가져옵니다.

## 배포 주소

- 정본: <https://kimjiwon-slide.vercel.app/easyai>
- 옛 주소 `/sbti4`는 `sbti4/index.html` 리다이렉트 페이지로 유지됩니다. 이 저장소에서는
  `vercel.json`의 `rewrites`가 실제로 적용되지 않으므로, 새 경로가 필요하면 리라이트가 아니라
  **실제 폴더나 리다이렉트 파일**을 만들어야 합니다.

## 정본 파일

- `index.html`: 실제 발표·배포용 최종 책자. 선택된 그림까지 data URI로 내장한 단일 HTML이라 이 파일 하나만으로 오프라인 실행할 수 있습니다.
- `visual-options/index.html`: 기존안과 신규안 총 16점을 비교하고 선택하는 갤러리입니다.
- `visual-options/*.png`: 표지·하네스·멀티에이전트·메모리별 신규 후보 3점씩, 총 12점입니다.
- `assets/ghost-*`: 갤러리의 기존안과 SBTI 유령 원본 자산입니다.
- `assets/*.jpg`: 제작 과정에서 만든 이전 콘셉트 후보와 보관용 이미지입니다.

## 현재 최종 선택

| 위치 | 선택안 | 그림 의미 |
| --- | --- | --- |
| 표지 | B 설계 테이블 | 역할이 다른 유령들이 한 도면을 함께 설계 |
| 하네스 | A 3단 검문 | 도구·보안·검증 게이트를 차례로 통과 |
| 멀티에이전트 | C 피드백 순환 | 계획→구현→검토 후 필요하면 다시 반복 |
| 메모리·LLM 위키 | A 위키 선반 | 검색·검증한 지식을 다음 세션용으로 축적 |

최종 선택 이미지는 `index.html` 안에 내장되어 있습니다. `visual-options/index.html`의 선택값은 브라우저 `localStorage`에도 저장되지만, 정본 판단은 위 표와 `index.html`을 우선합니다.

## 최신 전체 자료 받기

저장소 전체를 이미 받은 상태라면:

```bash
cd ~/kimjiwon_slide
git pull --ff-only origin main
open easyai/index.html
```

SBTI4 폴더만 sparse clone으로 새로 받으려면:

```bash
git clone --filter=blob:none --sparse https://github.com/flykimjiwon/kimjiwon_slide.git
cd kimjiwon_slide
git sparse-checkout set easyai
open easyai/index.html
```

## 로컬 실행

```bash
open easyai/index.html
open easyai/visual-options/index.html
```

별도 빌드나 서버가 필요하지 않습니다. 배포 시에는 `index.html`만으로도 열리지만, 시안 재선택과 전체 자산 보존을 위해 Git에는 `easyai/` 폴더 전체를 유지합니다.

## 책자 사용법 (2026-08-03 개편)

### 좌측 사이드바 (기본 접힘)
상단 가로 메뉴를 없애고 좌측 고정 사이드바로 바꿨습니다. 장별 아이콘·부제, 현재 읽는 위치 자동 하이라이트,
용어 전역 검색(본문 용어 카드 + 부록 사전 동시 검색 → 클릭하면 해당 위치로 이동·하이라이트)이 들어 있습니다.

**처음 열면 64px 아이콘 레일로 접혀 있습니다.** 상단 꺾쇠 버튼으로 펼치고 접으며, 선택은
`localStorage`(`sbti4-sidebar`)에 기억됩니다. 접힌 상태에서 돋보기를 누르면 자동으로 펼쳐지며 검색창에 포커스가 갑니다.
화면 폭 1120px 이하에서는 접기 개념 없이 좌측 하단 버튼으로 여닫는 전체 오버레이로 동작합니다.

### 아이콘
이모지를 전부 걷어내고 자체 제작 SVG 21종을 인라인 스프라이트(`#sbti4-sprite`)로 넣었습니다.
난이도 표기는 커피(누구나)·고추(개발자용) 아이콘, 오해/사실은 X·체크 아이콘입니다.
새 아이콘이 필요하면 스프라이트에 `<symbol>`을 추가하고 `<svg class="ico"><use href="#i-이름">`로 씁니다.
시스템 폰트 이모지는 다시 넣지 않습니다(OS·브라우저마다 모양이 달라 인쇄본이 깨짐).

### 인쇄 · PDF (A4)
사이드바의 `인쇄 · PDF(A4)` 버튼 또는 Cmd+P. A4 세로 기준으로 표지 1페이지, 장마다 새 페이지,
용어 카드·표·그림·인용은 페이지 중간에서 잘리지 않게 고정, 부록 사전은 2단, 출처는 마지막 페이지입니다.
현재 분량 기준 약 18페이지. 인쇄 시 사이드바·편집 UI는 자동으로 빠집니다.

### 편집 모드 (수정 요청 만들기) — 관리자 잠금
잠긴 상태에서 사이드바에 보이는 것은 `편집 모드 (잠김)`과 `인쇄 · PDF` 둘뿐입니다.
**`수정요청 전체 복사`·`입력 초기화`·`관리자 잠금`은 아예 노출되지 않습니다.**
`편집 모드`를 누르면 확인 창이 뜨고, 통과하면 세 버튼이 나타나며 그 탭에서만(`sessionStorage`) 유지됩니다.
새 탭·새 창은 다시 물어봅니다.
사이드바 하단 `관리자 잠금`으로 즉시 되잠글 수 있고, `?edit=1`로 열어도 비밀번호 없이는 편집이 켜지지 않습니다.
`인쇄 · PDF`와 읽기·검색은 잠금과 무관하게 누구나 씁니다.

> 단일 HTML의 클라이언트 잠금이라 **암호학적 보호가 아니라 오조작 방지용 게이트**입니다.
> 비밀번호는 소스에 해시로 들어 있고, 바꾸려면 `PWH` 상수(djb2 해시)를 교체하면 됩니다.
> 진짜 비밀은 이 책자에 넣지 않습니다.

잠금을 풀고 `편집 모드`를 켜면 표지·읽는 법 카드·장 도입문·용어 카드·팩트체크 카드·부록 그룹·푸터까지
**48개 블록마다 입력칸**이 생깁니다. 마음에 안 드는 설명이나 용어를 그 칸에 적으면 됩니다.

- 입력값은 브라우저 `localStorage`(`sbti4-edits-v1`)에 저장돼 새로고침해도 남습니다.
- `수정요청 전체 복사`를 누르면 입력한 것만 모아 **블록 위치·eid·현재 본문 발췌·요청 내용**이 담긴
  프롬프트가 클립보드에 복사됩니다. 그걸 대화창에 붙여넣으면 그대로 반영 작업을 시킬 수 있습니다.
- 각 블록의 `data-eid`(예: `ch1-term-4`)가 수정 대상 좌표입니다.
- `입력 초기화`로 전부 지웁니다. 편집 모드를 꺼두면 화면·인쇄본에 아무 흔적도 남지 않습니다.
- `index.html?edit=1`로 열면 편집 모드로 바로 시작합니다.

## 수정 원칙

- 발표 정본은 항상 `index.html`입니다.
- 새 그림을 채택하면 이미지와 캡션을 함께 수정합니다.
- 최종 책자는 단일 파일·오프라인 실행을 유지합니다.
- 후보 이미지는 삭제하지 않고 `visual-options/` 또는 `assets/`에 보관합니다.
- SBTI4와 무관한 저장소 변경은 같은 커밋에 섞지 않습니다.
