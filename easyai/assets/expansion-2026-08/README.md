## 공통 제작 문법

- 16-bit 픽셀 아트, 각진 픽셀·큰 유령 실루엣·글자 없는 교육용 장면
- `#07101d` 계열의 짙은 남색 도트 배경과 청록 네온 회로, 로열 블루 기반
- 노랑·주황·보라·분홍·라임은 역할 구분을 위한 제한적 포인트 색
- 텍스트·숫자·브랜드·로고·워터마크는 넣지 않음
- OpenAI 내장 이미지 생성 도구로 만들고, 실제 사용 전 슬라이드 문맥에 맞는 한 장을 선별하는 방식
