이 자료는 김지원이 업무 외 개인 시간에 기획·제작한 개인 저작물입니다.
아래는 본문에 쓰인 이미지의 제작 이력이며, **분쟁 시 "언제 어떻게 만들었는지"를 보이기 위한 기록**입니다.

- 정리일: 2026-08-04
- 대상: `easyai/` 아래 모든 이미지

## 1. C2PA 확인 방법

이미지가 계속 늘어나고 있어 총계를 문서에 고정해 두지 않습니다. 저장소 루트에서 아래를
실행하면 언제든 현재 상태를 셀 수 있습니다.

```python
import glob
for p in sorted(glob.glob('easyai/**/*.png', recursive=True)) + sorted(glob.glob('easyai/**/*.jpg', recursive=True)):
    d = open(p, 'rb').read(200000)
    print('있음' if (b'jumb' in d or b'c2pa' in d) else '없음', p)
```

### 묶음별 성격

| 묶음 | 성격 |
|---|---|
| `visual-options/` | 표지·하네스·멀티·메모리 후보와 MCP·A2A v1~v3. 대부분 C2PA 있음 |
| `assets/expansion-2026-08/` | 초기 후보팩. **가로 버전에만** C2PA가 남아 있고, 세로·정사각은 리사이즈 과정에서 메타데이터가 떨어졌습니다 |
| `assets/canonical-pixel-2026-08/` | 정본 픽셀팩. 본문에 실제로 쓰는 삽화가 여기서 나옵니다 |
| `assets/*.jpg` | 초기 제작분 4점. C2PA 이전이라 아래 표로 대체 기록 |

C2PA는 **제작 이력의 증거**이지 저작권 보증서가 아닙니다. 세로·정사각처럼 서명이 없는 파일도
같은 세션의 가로 원본에 서명이 남아 있으면 제작 이력은 그쪽으로 확인됩니다.
