## 2. AI 생성과 C2PA 확인

이미지가 계속 늘어나므로 `있음 N · 없음 N`처럼 변하는 총계를 이 문서에 고정하지 않습니다.
저장소 루트에서 다음 빠른 검사를 실행하면 현재 파일에 C2PA 관련 박스가 남아 있는지 확인할
수 있습니다.

```python
from pathlib import Path

paths = sorted(Path("easyai").rglob("*.png")) + sorted(Path("easyai").rglob("*.jpg"))
for path in paths:
    data = path.read_bytes()
    marker = b"jumb" in data or b"c2pa" in data
    print("표식 있음" if marker else "표식 없음", path)
```

이 코드는 **표식 유무를 찾는 빠른 검사**이지 서명 유효성을 검증하는 도구가 아닙니다.
서명·manifest의 유효성은 C2PA 검증 도구로 별도 확인해야 합니다. 리사이즈, 포맷 변환,
`data:` URI 재임베드 과정에서는 원본에 있던 메타데이터가 없어질 수 있습니다.

### 묶음별 성격

| 묶음 | 성격 |
|---|---|
| `visual-options/` | 표지·하네스·멀티·메모리 후보와 MCP·A2A 시안 |
| `assets/expansion-2026-08/` | 초기 후보팩. 가로 원본과 파생 비율 파일을 함께 보존 |
| `assets/canonical-pixel-2026-08/` | EasyAI 픽셀 문법을 적용한 정본·확장 후보. 개념·비율·채택 규칙은 폴더 `README.md`에 기록 |
| `assets/*.jpg` | 초기 생성분 4점. `ghost-search-to-memory.jpg`만 현재 본문에서 사용하고 나머지는 후보 보관 |

| 파일 | 쓰임 | 제작 |
|---|---|---|
| `assets/ghost-search-to-memory.jpg` | 6장 메모리·위키 삽화 | 2026-07 · OpenAI 이미지 생성 도구 보조 · 콘셉트·프롬프트·선별·편집 김지원 |

C2PA는 생성·수정 이력을 확인하는 provenance 장치입니다. 표식이 있다는 사실만으로 저작권,
상표권, 초상권 또는 제3자 권리 검토가 끝나는 것은 아닙니다.

### PAC-MAN 비참조 확인

2026-08-03 Codex 생성 기록의 imagegen 호출 16건을 점검했습니다.

- 이미지 참조 없음: 14건
- 로컬 `ghost-crew-hero.svg` 렌더만 참조: 2건
- 생성 입력에서 `Pac-Man`, `pacman`, `팩맨`, `Bandai`, `남코`: 0건
- PAC-MAN 이미지·로고·캐릭터 이름을 생성 레퍼런스로 사용한 기록: 확인되지 않음

시각 문법도 큰 사각 픽셀, 계단형 머리, 사각 눈과 동공, 분홍 볼, 각진 블록 발,
안전모·스카프·공구·가방, 기술 신호선·제어 코어를 중심으로 합니다. PAC-MAN의 공식 캐릭터
명칭, 로고, 미로, PAC-DOT, POWER-PELLET, 노란 원형 주인공은 사용하지 않습니다.

이 기록은 독립 제작 계보를 뒷받침하지만 법적 면책을 보증하지는 않습니다. 상세 커밋,
시각 비교, 법률·약관 해석은 부모 워크스페이스의
`docs/analysis/PIXEL_CREW_ORIGIN_AND_PACMAN_RISK_AUDIT_2026-08-04.md`가 정본입니다.

## 5. 본문 구성과 원본 보존

현재 `easyai/index.html`은 여러 제작 방식을 함께 사용합니다.

- 주요 픽셀 삽화: PNG·JPEG를 `data:` URI로 임베드
- 설명 도식과 아이콘: 인라인 SVG로 직접 구성
- 확대 가능한 제품 화면: 직접 캡처한 사본을 임베드
- 생성·편집 원본: `easyai/assets/`와 `visual-options/`에 별도 보존

따라서 과거 설명처럼 “그림 1~10이 전부 인라인 SVG”로 고정하지 않습니다. 본문 채택본이
바뀌어도 원천 파일, 생성 묶음 README, 이 문서를 함께 보면 제작 이력을 다시 찾을 수 있어야
합니다.

## 6. 권리·표시 원칙

1. GPT·Codex 등 생성 도구를 사용했다는 사실만으로 제3자 권리가 자동 정리되지는 않습니다.
2. C2PA는 제작 이력 증거이며 저작권·상표권 보증서가 아닙니다.
3. 자료의 CC BY-NC 4.0 표시는 김지원에게 권리가 있는 편집·설명·삽화 범위에 적용됩니다.
   제품 화면, 상표, 로고 등 제3자 요소의 권리를 새로 부여하지 않습니다.
4. Pixel Crew 설명·마케팅에 PAC-MAN, 공식 고스트 이름, 미로·점·펠릿 조합을 사용하지 않습니다.
5. 캐릭터 자체를 독립 상업 상품·굿즈·브랜드 마스코트로 확장할 때는 대표 실루엣과 표지를
   다시 검토합니다. 현재 공개 교육자료만으로 전량 재생성하거나 팔레트를 바꿀 근거는 없습니다.
6. TECHAI CODE가 인라인 사용하는 Lucide Ghost SVG의 ISC 고지는 해당 제품의 제3자 라이선스
   문서에서 별도로 관리합니다. 이는 EasyAI의 PAC-MAN 유사성 판단과는 다른 항목입니다.
