# kimjiwon_slide

택가이코드 발표자료 최종본입니다.

## 보기

- 메인: `index.html`
- 보조 사본: `택가이코드_발표자료_v2.html`, `택가이코드_발표자료.html`
- 이미지/영상/SVG asset: `assets/`

## Vercel 배포

이 저장소는 별도 빌드가 필요 없는 정적 HTML 사이트입니다.
Vercel에서 GitHub 저장소를 연결한 뒤 Framework Preset을 `Other` 또는 Static으로 두면 `index.html`이 바로 배포됩니다.
