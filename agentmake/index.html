03 · Core Formula

에이전트를 이루는
핵심 공식

  • 01목표와
    완료조건    무엇을, 어디까지
  • 02모델해석과 다음 행동 선택
  • 03컨텍스트와
    상태    지금까지 무엇을 아는가
  • 04도구와
    실행환경    세상에 어떻게 작용하는가
  • 05관찰 기반
    실행 루프    결과로 다음 행동 변경
  • 06권한과
    검증    어디까지, 무엇으로 확인

LLM 기반 에이전트의 본질은 모델 하나가 아니라, 목표를 향해 상태를 바꾸고 그 결과를 다시 판단하는 시스템입니다.

06 · Model vs Harness

모델은 판단하고,
하네스가 행동합니다

Decision Engine LLM 모델
  • 사용자 의도와 제약 해석
  • 다음 행동과 도구 선택
  • 도구 결과의 의미 해석
  • 완료, 재시도, 질문 판단
→
Execution Engine 하네스
  • 도구 스키마와 인자 검증
  • 권한 확인과 샌드박스 실행
  • 오류, 출력, 상태를 모델에 반환
  • 로그, 비용, 시간, 중단 관리

09 · Bounded Adaptive Loop

고정 N회가 아니라
결과에 따라 바뀌는 루프

  1. 01목표 확인
  2. 02상태 관찰
  3. 03행동 결정
  4. 04권한 확인
  5. 05도구 실행
  6. 06결과 검증
  7. 07완료 판단
DONE완료조건 충족, 증거와 함께 종료
RETRY실패 원인을 반영해 다른 행동 선택
RECOVER체크포인트로 되돌리고 상태 복구
HANDOFF권한 또는 판단이 필요하면 사람에게 질문

12 · Final Definition

에이전트의
필수요소

에이전트는 목표와 완료조건을 받아, 현재 컨텍스트와 상태를 관찰하고, 모델이 다음 행동을 선택하며, 권한이 부여된 도구를 실행하고, 그 결과를 검증하면서 완료, 복구, 중단까지 반복하는 시스템입니다.

  • 01 · 누가 무엇을 위해 쓰는가?
  • 02 · 완료를 무엇으로 증명하는가?
  • 03 · 어떤 상태를 보고 판단하는가?
  • 04 · 어떤 도구로 무엇을 바꾸는가?
  • 05 · 어디까지 허용하고 언제 묻는가?
  • 06 · 실패하면 어떻게 복구하고 멈추는가?
